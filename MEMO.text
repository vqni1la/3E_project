自動運転のプログラムをpythonというプログラミング言語で作りました。
遺伝的アルゴリズムという生物の進化を模倣して作られたプログラムです。
最初はランダムな遺伝子(データ)ですが、優秀なデータを次の世代に引き継がせたり(自然淘汰)、データ同士をかけ合わせたり(交叉)、全く関係のないデータを読み込ませたり(突然変異)などをして、AIを進化させます。

センサーで壁との距離を測り、その距離によってスピードや車の向きを変えます。
AIの走行が終わったら、行動を評価してあげて適応度を計算し、各個体に優劣をつけた後に遺伝子操作を施して、AIを進化させるという仕組みです。

操作一覧(マウスクリック操作可能){
  S           : センサーオンオフ
  M           : プレイヤーモード & 学習モードの切り替え

  1           : コース1 ただの四角
  2           : これ使わないで
  3           : コース3 ひし形
  4           : コース4 ぐねぐね
  5           : コース5 ぐねぐね
  6           : コース6 ちょい丸っぽい四角

  学習リセット : reset Learning
  時間速度変更 : ＋ - のボタンを押す

  プレイヤーモード{
    W : 前進
    S : 後進
    D : 右に回転
    A : 左に回転

    R : プレイヤーリセット
  }
}

ラジコンキット(モーターとタイヤと車体) : Annadue 4WD
モーター制御 : TB6612FNG
マイコン : ESP32-WROOM
操作 : 差動駆動
センサー : 赤外線センサー
