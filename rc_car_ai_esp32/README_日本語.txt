3E Car Simulator → ESP32 自動運転・統合ファームウェア（初期版）

■ ファイル
- rc_car_ai_esp32.ino：手動モードとAI自動運転モードを統合したスケッチ
- best_genome_weights.h：添付された best_genome.json の重み66個

■ 添付されたPythonコードから確認した仕様
- ニューラルネットワーク：入力5個 → 隠れ層8個（tanh）→ 出力2個（tanh）
- output[0]：操舵（-1～1）
- output[1]：速度・後退（-1～1）
- 重みの順序：W1（5×8）、b1（8）、W2（8×2）、b2（2）で合計66個
- 添付モデルは第7世代、fitness=3870.793285190802
  これは第7世代時点の保存データであり、実機で安定走行できる保証はない。

■ この初期版が想定するセンサー（まだ実機未確認）
- SHARP GP2Y0A21YK0F アナログ距離センサーを5個
- 車体前方から見て、左から右へ -60°、-30°、0°、+30°、+60°
- センサー出力の接続先：GPIO32、GPIO33、GPIO34、GPIO35、GPIO36（この順序）
- シミュレーター側の入力は [-60, -30, 0, +30, +60] の順なので、順序を変えないこと

■ 配線の重要事項
1. GP2Y0A21YK0Fは4.5～5.5Vで動作する。ESP32の3.3V端子やGPIOから給電しない。
2. センサー5個の電流に対応できる安定した5V電源を使う。センサー1個の標準消費電流は約30mAなので、5個では合計約150mAを見込む。
3. センサー電源の近くに10µF以上のコンデンサーを入れることを推奨する。
4. ESP32のADC入力保護のため、各センサーのVOに分圧抵抗を入れる：
   センサーVO → 10kΩ → ADCノード → GPIO32/33/34/35/36
   ADCノード → 20kΩ → GND
   この分圧比（2/3）をコードで補正する。抵抗をセンサーごとに用意する。
5. ESP32、センサー電源、前後2個のTB6612FNG、モーター用バッテリーのGNDを共通にする。
6. モーター制御ピンは現在の手動版v4を維持し、STBYはGPIO26とGPIO27で制御する。STBYを3.3Vへ直結しない。
7. センサーを取り付ける際は、正面に近い方向だけでなく、左右のセンサーをそれぞれ指定角度に向ける。

■ 最初はAIモードを無効にしてある
コード冒頭の SENSOR_HARDWARE_READY は false。センサーをまだ購入・配線していない段階でAIが誤った距離値を使って走行しないため。

センサーを取り付けた後の手順：
1. ENABLE_SENSOR_DIAGNOSTICS を true にして書き込み、シリアルモニター（115200 baud）で5個の距離値を確認する。
2. 壁を遠ざけると距離値が増えること、各センサーがそれぞれの向きの壁を認識することを確認する。
3. センサー値が妥当になったら、SENSOR_HARDWARE_READY を true に変更して再書き込みする。
4. Yボタンで手動／AI自動運転を切り替える。Bボタンを押している間は停止し、手動モードに戻る。
5. センサーが無効な値を返したとき、またはセンサーの測定範囲外に近づきすぎたと判定したときは、モーターを停止する。

■ 初期の自動運転出力制限
- AUTO_MAX_PWM=120
- AUTO_THROTTLE_LIMIT=0.45
- AUTO_STEERING_LIMIT=0.45
- AUTO_TURN_GAIN=1.0

最初の実機テスト用に出力を制限している。必ず車体を台に載せ、タイヤを浮かせてモード切り替えと停止動作を確認する。その後、広く囲われたコースで低速から試す。安全確認なしに出力制限を外さないこと。

■ センサー距離変換
GP2Y0A21YK0Fの近似式：距離(cm) = 29.988 × 電圧(V)^(-1.173)
測定範囲は10～80cm。個体差があり、10cm未満では距離を誤認する可能性があるため、コードでは近づきすぎた電圧を検出した場合に停止させる。
センサー距離10～80cmを0～1に変換し、Python側の距離/150の正規化済み入力に対応させている。ただし、実コース寸法・センサーの向き・壁の反射特性による調整が必要。

■ 注意
このZIPは、提供されたPythonコードと手動版v4を元に作成した初期統合版。使用しているArduino/Bluepad32環境でのコンパイル、実際のセンサー測定、実車走行はまだ確認していない。センサー未接続ではAIモードを有効にしないこと。
